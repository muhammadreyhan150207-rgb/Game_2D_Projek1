## Lingkungan

- Unity 6 (seri 6000.x), sesuai ketentuan modul
- Versi yang dipakai tim: **6000.3.23f1**. Semua anggota harus memakai versi yang sama dan **JANGAN upgrade**
- Template: Universal 2D, Input System

## Cara Menjalankan

1. Buka Unity Hub, pilih **Add > Add project from disk**, lalu pilih folder proyek ini.
2. Buka dengan Unity 6000.3.23f1.
3. Buka `Assets/Scenes/Scn_Bootstrap.unity` lalu tekan Play.

## Alur Kerja

- Branch: `NamaLengkap_NIM` (satu branch per anggota)
- Commit: awali dengan `feat:`, `fix:`, `art:`, atau `chore:` lalu ringkasan
- Urutan kerja:
  1. Fetch
  2. Update from main
  3. Kerjakan tugas
  4. Tutup Unity
  5. Commit
  6. Push
  7. Buat Pull Request

## Aturan Kode

- Class dan method: `PascalCase`
- Field private: `camelCase` dengan `[SerializeField]`
